ゲームについて

青いドラゴンにごはんをあげ、お風呂に入れ、寝かせてあげよう。天空アリーナでリングを通り、星の道でタイルを選び、星をつかまえて遊べます。

進み具合、持ち物、記録はこの端末に保存されます。ゲーム内で撮った写真は端末内のアルバムに保存されます。

Android 0.3.9 (12) · rs.zoko.game · VS Studio · Vladan Stanisavljevic

ヘルプ

食事とお世話

ごはんを選ぶとキッチンが開きます。りんご、ごはん、クッキーを選ぶか、食べ物をZOKOまでドラッグしてね。満腹のときは食べ物は消費されません。お風呂では石けんを体の上で動かし、シャワーで泡を流します。眠るとエネルギーが回復し、休憩のお知らせをタップすると起こせます。

ミニゲーム

天空アリーナでは指をドラッグして飛ぶ方向を操作します。シールドは衝突を1回防ぎ、マグネットはコインを引き寄せます。星の道では金色のタイルをタップします。星をつかまえようでは、時間内に星をタップしてください。

保存と引き継ぎ

設定のバックアップで進み具合の書き出しや読み込みができます。アルバムの写真は別に書き出します。アプリの削除やアプリデータの消去をすると、端末内の進み具合とアルバムは消えます。残したいものは先に書き出してください。

終了とトラブル

戻る操作で部屋やウィンドウから戻れます。メインの部屋では終了確認が開きます。3D表示が動かない場合はAndroid System WebViewを更新し、アプリを再起動してください。問題の報告には端末の機種、Androidのバージョン、症状を添えてください。連絡先：laservlada82@gmail.com。

プライバシー

端末内のデータ

進み具合、レベル、仮想通貨、持ち物、記録、デイリーミッション、設定は端末内に保存されます。ゲーム内で作成したZOKOの写真は端末内のアルバムに最大20枚保存されます。これらの画像に端末のカメラは使いません。

データの送信

確認済みの版にはアカウント、広告、分析ツール、実際のお金を使う購入機能はありません。ゲームは進み具合やアルバムの写真を発行者へ送信しません。素材はアプリに同梱され、Androidでのリクエスト先はアプリのローカルオリジンに制限されます。連絡先、マイク、位置情報へのアクセスは要求しません。

ファイルと共有

利用者の操作により、Androidのファイル選択画面でバックアップの読み込みや書き出しを行います。書き出したファイルはアプリとは別に存在します。他のサービスを通じて共有する場合、そのサービスの規則が適用されます。

削除と子ども

写真はアルバムで削除できます。端末内のデータはAndroidのアプリ設定から消去するか、アプリを削除することで消せます。書き出し済みのコピーはこの操作では消えません。プレイヤーに個人情報の提供は求めません。対象として予定しているのは13歳以上のプレイヤーと大人です。これは公式の年齢レーティングではありません。

今後の変更

広告や購入機能を予定していますが、この版では有効になっていません。広告、分析、アカウント、購入などのサービスを有効にする前に、このポリシーとGoogle Playへの申告を更新し、対象利用者に関する要件を確認する必要があります。

Androidアプリにはインターネット権限がありますが、WebViewはアプリ内のローカルリソースのみを読み込みます。Androidの自動バックアップは無効です。

GitHub Pages

このサイトはGitHub Pagesを使用しています。GitHubは安全確保のためIPアドレスを記録する場合があります。各ページには解析、広告、追跡スクリプトはなく、独自のCookieも設定しません。

GitHub · Privacy

メールを送ると、お問い合わせへの対応のためアドレスと本文を受け取ります。適用される保存義務の範囲内で、やり取りの削除を依頼できます。

ルール

テスト版のルール

ZOKOは仮想のドラゴンをお世話するゲームです。コイン、ダイヤ、報酬は仮想のもので、金銭的価値はなく、現金への払い戻しや交換はできません。

進み具合は端末内に保存されます。アプリデータの消去や機種変更の前にバックアップを書き出してください。テスト版には不具合が含まれる可能性があり、技術的な中断で進み具合を失う場合があります。
